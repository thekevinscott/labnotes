**Added** — runs whose process died without labnotes noticing (daemon killed, machine rebooted) no longer show as running forever. When the daemon starts, it ends each unfinished run whose `pid` is gone or reused, writing `"ended_by": "lost"` and the time it noticed as `ended` to `run.json`. `exit_code` stays `null`. A run whose process is still alive stays unfinished until a later daemon start finds it gone.
