Added: `continues = true` in a matrix experiment's `experiment.toml` invokes a failed run again in its own folder instead of starting a new one. Its `run.json` lists each invocation under `invocations`, each invocation writes its own `stdout-<time>.txt` and `stderr-<time>.txt`, and a `run.lock` in the folder marks a run that is still going. Exit 75 retries of such an experiment run in the same folder.
