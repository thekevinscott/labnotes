**Added** — `labnotes experiments NAME run --timeout DURATION` stops any one run still going after DURATION, like `labnotes run stop` does: SIGTERM, then SIGKILL 5 seconds later. It takes seconds (`90`) or units (`30s`, `10m`, `1h30m`). The run's `run.json` records `"error": "timed out after 10m 00s"` beside its exit code, and the run's web page now shows a run's error in place of its exit code. Unset, runs have no time limit, as before.
