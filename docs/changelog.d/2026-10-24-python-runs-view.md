**Added** — runs views. Set `[views] runs` to a command in `experiment.toml` (or under `[experiment]` in `.labnotes.toml`) and the TUI's experiment screen adds the columns it returns. The script speaks newline-delimited JSON on stdin and stdout; `from labnotes import view` and `@view.serve` handle the protocol. labnotes asks again for a run when a file in its folder changes. A line under the table shows a rejected or slow (over 100 ms) answer. See `docs/api/views.md`.
