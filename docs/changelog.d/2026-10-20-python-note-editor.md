**Added** — Click a note in the Notebooks tab of `labnotes server` to edit its markdown in place. Edits save to the file as you type; Escape or a click outside the note shows it rendered again, and Run uses the saved blocks. If the file changed on disk since the page loaded, the save is refused and the editor says so. The editor (CodeMirror) loads from esm.sh, so offline the note stays read-only and runnable, with a hint that editing needs the network.
