Changed: with `continues = true`, `retries` now also caps how many times a later `run` invokes a failed run again. Every invocation after the first spends one retry, whether from exit 75 or a later `run`, except invocations stopped by hand. A run out of retries keeps its cell short and `run` prints `N cells gave up after R retries.` The `retries` default goes from 2 to 3. Added `run --retries N` to override it for one run, and `run --replace-capped` to give an out-of-retries cell a fresh run.
