**Added** — `.labnotes.toml` takes an `[experiment]` table with the same keys as `experiment.toml`. It is the base each `experiment.toml` layers over: top-level keys replace, `params` merge by name, and the merged result is validated. With no `[experiments] path`, `[experiment]` alone makes the root the one experiment; with one, it gives every experiment its defaults. `run -e PATH` replaces only the `experiment.toml` layer.
