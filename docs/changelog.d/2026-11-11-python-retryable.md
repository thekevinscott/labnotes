Added: a `retryable` config key, in `[experiments]`, `[experiment]` and `experiment.toml`, names a command that decides whether a failed run is retried. labnotes writes the attempt to its stdin as JSON (exit code, times, params, log paths and more); exit 0 retries, anything else gives up. With no `retryable`, only exit 75 is retried, as before. The TUI and messages now name the exit code a run retried or gave up on, not always 75.
