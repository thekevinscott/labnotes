**Added** — a run whose command exits 75 (`EX_TEMPFAIL`) is retried with the same params, after 30 seconds and then twice as long each time. `retries` in `experiment.toml`, or under `[experiments]` in `.labnotes.toml`, sets how many (default 2, 0 turns them off). Each retry gets a new run folder whose `run.json` holds `retry_of`; manual retries set it too. Other exits and stopped runs never retry. The runner reports `retrying`, `gave up` and `retry cancelled` events, the TUI shows the countdown and `gave up (exit 75)`, and the `run` summary counts retried runs apart from failed ones.
