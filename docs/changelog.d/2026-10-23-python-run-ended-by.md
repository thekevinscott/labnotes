**Added** — `run.json` records why a run ended. `ended_by` is `"timeout"` for `--timeout`, `"stop"` when labnotes stopped the run (`run stop`, the quit prompt, a kill from the TUI), `"signal"` when a signal labnotes didn't send ended it (the out-of-memory killer, a person), and `null` for a normal exit. `signal` holds the signal number, read from a negative exit code or a shell's 128 + N. Older `run.json` files lack both keys.
