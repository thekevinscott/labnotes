**Added** — `labnotes experiments NAME run --timeout SECONDS` stops any one run still going after that many seconds, like `labnotes run stop` does: SIGTERM, then SIGKILL 5 seconds later. The run's `run.json` records, for `--timeout 600`, `"error": "timed out after 10m 00s"` beside its exit code, and the run's web page now shows a run's error in place of its exit code. Unset, runs have no time limit, as before.
