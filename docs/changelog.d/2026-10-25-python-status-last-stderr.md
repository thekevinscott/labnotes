**Added** — `run status` shows why a run failed. When a run ends with a non-zero exit, an error, a signal or a timeout, its end line adds the last non-blank line of its `stderr.log`, like `exp: r1 exited 1: ValueError: boom`. With `--json`, the `ended` event carries it as `last_stderr`. labnotes reads the log back from its end, so large logs cost nothing extra. A missing or empty log adds nothing.
