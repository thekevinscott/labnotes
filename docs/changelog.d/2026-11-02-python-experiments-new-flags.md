**Added** — `labnotes experiments new NAME` takes `--command`, `--param NAME=VALUE` (repeatable; values parse as TOML, else a string) and `--repeats`, and writes them into the new `experiment.toml`. `--from OTHER` copies another experiment's `experiment.toml` and files, never its runs, and records `from = "OTHER"`; the other flags replace the copied values. `experiment.toml` accepts the new `from` key.
