**Added** — `from labnotes import log` gives scripts a way to write structured output. Each call appends one JSON block, stamped with a UTC timestamp, to `log.jsonl` in the run folder, which the runner names through the `LABNOTES_LOG` environment variable. Blocks are complete, or stream in `start` / `delta` / `stop` phases tied by `id`. Run outside labnotes, `log` prints the block's `content` to stdout. See the [SDK docs](../api/sdk.md).
