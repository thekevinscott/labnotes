**Added** — each run's memory and folder size. The live TUI has `memory` and `size` columns, `labnotes run status` reports what each running run uses (a `usage` event with `--json`), and `labnotes experiments NAME runs` lists `memory` and `size` per run. Memory is the resident memory of the run's command and everything it started, sampled when the view reads it; finished runs show size only. `run.json` now records the command's `pid`.
