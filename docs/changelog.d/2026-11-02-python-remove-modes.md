**Removed** — **BREAKING** The `adhoc` / `matrix` split is gone. Every experiment plans the way `matrix` did: `run` plans only the combinations short of `repeats`, and a finished experiment plans nothing. Runs land in flat, stamped folders under `runs/`; older nested runs still list and count. Setting `mode` anywhere is a config error, and `continues` is now required in every experiment. `{invocation_dir}` always equals `{run_dir}`, the hook state file is always temporary, and a second `run` of an experiment that is already running refuses. See [the migration](../migrations.d/2026-11-02-python-remove-modes.md).
