**Fixed** — a param named like a `runs` column (`id`, `command`, `meta`, `error` and the rest) or like `started` or `duration` no longer gives the experiment's runs query two columns of that name. The run's own column wins, the value stays in `params`, and labnotes warns once naming the clashing params. The clash set comes from the `runs` table's columns, so it follows new `run.json` fields.
