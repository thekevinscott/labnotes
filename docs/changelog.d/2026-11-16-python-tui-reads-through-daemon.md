**Changed:** The run TUI and its views read experiment state through the daemon instead of opening their own index, so more TUI windows add no file watches. The daemon serves a new `GET /experiment` stream: the experiment as views see it, then the paths of changed run files and fresh state when runs change. A TUI whose idle daemon has gone starts another and stays live. The memory column now shows the latest sample from `memory.jsonl` while a run is live.
