# Philosophy

`labnotes` is designed to work entirely with local files, which distinguishes it from many other tools available for running and managing experiments.

Your experiments are already folders on your disk. Other tools copy them into a hosted service or a database you have to run, and your notes end up somewhere else again. `labnotes` leaves everything where it is. There's nothing to sign up for or set up, `grep` and git keep working, and if you stop using `labnotes` you lose nothing. Agents can read your experiments the same way you do: as files.

`labnotes` organizes its data largely by folder; folders structure how it views files. That said it is designed to be [customizable](api/config) to fit your local data setup.
