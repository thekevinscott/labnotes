**Changed** `labnotes <exp> run` no longer writes an event journal per invocation under `~/.local/state/labnotes/run-state/`. Those files were never read back or pruned, so the folder grew with every run. The daemon now names each batch with its own id instead of a journal path, and `labnotes <exp> attach` still finds live batches by asking the daemon. `run-state/` now holds only the daemon's `README`, locks, and socket records. Old `*.jsonl` journals there are safe to delete.
