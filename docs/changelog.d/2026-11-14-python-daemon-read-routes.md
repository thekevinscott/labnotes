Added read routes to the experiment daemon's socket: `GET /runs`, `GET /runs/{id}/files` and `GET /runs/{id}/files/{file}`. Each is a server-sent event stream: current state first, then changes, every event with an id that `Last-Event-ID` resumes from. Binary files return size and type, not content. The daemon opens one DirSQL rooted at the experiment, so more readers add no file watches.
