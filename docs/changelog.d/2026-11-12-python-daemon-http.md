**Changed:** the experiment daemon now speaks HTTP on its Unix socket. `GET /batches` lists active batches, `GET /events` streams them as server-sent events, and `POST /start`, `/restart`, `/stop`, `/finish-up`, `/concurrency`, `/runs/{run}/stop` and `/runs/{run}/start` drive them. `curl --unix-socket <socket> http://labnotes/batches` works. The run and attach TUIs talk to the daemon through these routes.
