**Removed** — **BREAKING** `{invocation_dir}` is no longer filled in `setup`, `teardown`, or `meta`. Using it there fails the invocation before setup, as `{run_dir}` already did. Share values with `set_state()` and `get_state()` instead. An `[env]` value that uses `{invocation_dir}` is left out of the hook environment; runs still get it, including in matrix mode with several runs, which used to fail. `{invocation_dir}` in run commands is unchanged. See [the migration](../migrations.d/2026-11-01-python-no-hook-invocation-dir.md).
