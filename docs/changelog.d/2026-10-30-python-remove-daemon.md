**Removed** — **BREAKING** labnotes no longer starts a per-project daemon. `experiments NAME run` owns its runs in the foreground and stops them on Ctrl-C, SIGTERM, SIGHUP, or TUI quit. The live `run status`, `run stop`, and `run control` commands and the Claude Code mod pane are removed. Agents should run experiments in a dedicated tmux window.
