**Added** — a project can be one experiment: when `experiment.toml` sits next to `.labnotes.toml`, labnotes treats the root as the experiment, named after its folder. Paths drop `{experiment}` (files default to `files/`, runs to `runs/{run}`), `[experiments] path` is rejected, and `experiments new` refuses. `labnotes init` writes these defaults when it finds an `experiment.toml`. Projects without a root `experiment.toml` behave as before; one that had a stray root `experiment.toml` now switches to this mode.
