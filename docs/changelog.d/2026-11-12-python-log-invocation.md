**Changed** — In a run that [continues](../api/config.md#continues), `log` tags each block with `invocation`, the start stamp of the invocation that wrote it (from the new `LABNOTES_INVOCATION` variable). The TUI's blocks view labels each invocation's blocks, and a streaming block a dead invocation left open is no longer extended by the next one. The web view doesn't label them yet.
