**Changed** — The TUI output view and the web run page read only the lines on screen, so a large log opens fast and uses little memory. The web page now fetches the lines it shows instead of receiving the whole log over its event stream. In the TUI, long lines wrap instead of scrolling sideways, so the view has one scrollbar. Both views follow new output while scrolled to the bottom, let go when you scroll up, and follow again once you scroll back down. Scrolling moves one log line at a time. A line longer than 64 KB shows its first 64 KB.
