**Added** — `setup` and `teardown` keys in `experiment.toml` or `[experiment]` in `.labnotes.toml`, and `--setup` / `--teardown` on `experiments NAME run`. Each is a shell command that labnotes runs once per invocation from the project root: setup before the first run starts, teardown after every run has ended, whether runs passed, failed or were stopped. `experiment.toml` overrides `.labnotes.toml`, and the flags override both. A failing setup starts no run and skips teardown; a failing teardown fails the invocation.
