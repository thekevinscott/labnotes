**Added:** a file browser view for the run TUI. Add `files = "labnotes.tui.file_browser:FileBrowser"` under `[views]` to list the selected run's files, kept current as the run writes them, and tail the file you choose. Views select a run with `labnotes.view.Select`, learn the selected run from `labnotes.view.Selected`, and read the daemon through `Changed.daemon`. The daemon's file tail now sends a fresh 64 KiB tail when a file grows by more than that between changes, instead of every new byte.
