**Fixed** Deleting `~/.local/state/labnotes/run-state` under a live daemon no longer cuts the TUI off from it. Clients find a daemon by its listening socket when the record or lock is gone, and a second daemon no longer unlinks a live socket. If the daemon dies while a TUI is attached, the TUI covers the view with a notice and exits with an error when you quit, so a stale view never reads as live. The daemon writes a `README` into `run-state` saying it holds live state.
