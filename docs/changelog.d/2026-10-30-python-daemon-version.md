**Fixed**: `labnotes experiments NAME run` used whatever labnotes version and `.labnotes.toml` the project's daemon started with, so edits to `.labnotes.toml` and upgrades did nothing while a long run kept an old daemon up. Each run now reads `.labnotes.toml` as it is on disk. Each labnotes version starts its own daemon, so a new version runs beside an older daemon, which finishes its runs and exits as before. `labnotes run status`, `run stop` and `run control` reach only the daemon of the version you call them with.
