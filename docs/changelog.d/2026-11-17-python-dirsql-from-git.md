**Changed:** labnotes now takes dirsql from GitHub main, pinned to a commit, because the PyPI release is frozen at 0.4.154 without the dirsql#1719 fixes. Installing from a git checkout or `uvx --from git+...` now builds dirsql from source, so it needs a Rust toolchain (`cargo`) on the machine. A labnotes wheel published to PyPI still declares plain `dirsql>=0.4.136` and gets the old PyPI dirsql.
