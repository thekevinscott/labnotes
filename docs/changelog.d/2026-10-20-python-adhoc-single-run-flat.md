**Changed** — An `adhoc` `run` command that plans a single run now writes it to one flat folder named for the time it was planned, like `runs/20261020-000429-brave-fox`, instead of nesting it as `runs/20261020-000429-brave-fox/quiet-river`. Commands that plan more than one run still nest. On the experiment page in `labnotes server`, a flat run among grouped invocations shows as a plain row. Runs already on disk read as before.
