**Added** — a `meta` key in `experiment.toml` or `[experiment]` in `.labnotes.toml`. It is a shell command that labnotes runs once when `run` starts, from the project root; its stdout must be one JSON object, such as the git commit. Every run the invocation starts, retries included, records it as `meta` in its first `run.json` write, and the `runs` table gains a `meta` column. A failing command, or output that isn't a JSON object, stops the invocation before any run starts. Queued runs keep the value from the start of the invocation.
