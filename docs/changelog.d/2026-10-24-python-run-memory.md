**Added** — each run's memory over time. While a run goes, labnotes appends a sample to `memory.jsonl` in its run folder: one JSON line with `time`, `rss` (resident bytes of the command and everything it started) and `processes`, flushed per sample and kept for the whole run. `memory_interval` in `experiment.toml` or `[experiment]` sets the seconds between samples (default 5; 0 turns it off). The samples are queryable as the `memory` table, one row per line.
