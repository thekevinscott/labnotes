**Changed** — `labnotes experiments NAME run -- ARGS` now overrides a flag already in the experiment's `command` instead of refusing it. `-- --memory 24g` turns `--memory 8g` into `--memory 24g` where it sits, and `--memory=8g` into `--memory=24g`. Flags the command lacks are still appended. A flag the command has more than once, or one ARGS give more than once to override it, is an error. Params are still picked with `--PARAM=VALUE`.
