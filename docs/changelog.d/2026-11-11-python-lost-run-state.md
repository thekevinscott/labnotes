**Fixed** Deleting `~/.local/state/labnotes/run-state` under a live daemon no longer cuts the TUI off from it. Clients find a daemon by its listening socket when the record or lock is gone, a second daemon no longer unlinks a live socket, and the TUI keeps reading a journal that was recreated. If the daemon dies while a TUI is attached, the TUI shows that at once and does not keep showing the old state as live. The daemon writes a `README` into `run-state` saying it holds live state.
