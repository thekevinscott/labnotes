**Added** — `labnotes experiments NAME run --PARAM=VALUE` runs only the cells where that param has that value, like `--model=small`. PARAM must be declared in `[params]` and VALUE must be one of its values; anything else is an error. Several params narrow further. It changes only what that `run` starts: counts, progress, `repeats` and the runs grid still cover the full matrix. Adhoc experiments filter their grid the same way.
