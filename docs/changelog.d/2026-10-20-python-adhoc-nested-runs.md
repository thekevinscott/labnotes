**Changed** — `labnotes experiments NAME run` in `adhoc` mode makes one folder per command, named for its UTC start time, and nests that command's runs inside it (`runs/20261020-000429-brave-fox/quiet-river`). The run id is that path. `fill` runs stay flat. `run.json` no longer has `invocation_id`; the parent folder groups runs instead. The live view shows each nested run by its own name.
